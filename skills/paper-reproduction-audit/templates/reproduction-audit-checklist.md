# Reproduction Audit Checklist Template

## Configuration

- [ ] resolved config is saved
- [ ] important version information is recorded

## Seeds And Budget

- [ ] seed set is explicit
- [ ] training budget is explicit

## Checkpoint Rule

- [ ] reported checkpoint rule is defined before comparison
- [ ] reported checkpoint is recorded

## Evaluation Protocol

- [ ] fixed evaluation protocol is recorded
- [ ] primary reported metric is explicit

## Required Artifacts

- [ ] experiment manifest
- [ ] checkpoint manifest
- [ ] logs
- [ ] eval outputs
- [ ] summary outputs

## Aggregation Rule

- [ ] aggregation rule is recorded
- [ ] exclusions or incomplete-run handling is recorded

## Final Reporting Questions

- [ ] what actually ran?
- [ ] which seeds were used?
- [ ] which checkpoint was reported?
- [ ] how was evaluation defined?
- [ ] how were results aggregated?
- [ ] what differs from the target baseline or paper?
