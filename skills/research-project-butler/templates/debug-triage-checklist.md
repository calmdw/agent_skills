# Debug Triage Checklist

- `Issue Summary`:
- `First Evidence Files`:
  - scheduler or runtime log
  - resolved config
  - episode metrics or run summary
  - eval metrics or eval summary
  - checkpoint manifest
- `Likely Layer`:
  - `runtime`
  - `training`
  - `evaluation`
  - `aggregation`
  - `deployment`
- `What To Confirm Before Forming A Hypothesis`:
- `Next Action`:
- `Should This Become A Tracked Task`:
  - `yes`
  - `no`
