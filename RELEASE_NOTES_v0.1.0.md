# Release Notes: `v0.1.0`

## Positioning

`v0.1.0` is the first usable personal skill library baseline.

## This Release Includes

- a standalone reusable skill-library structure
- library-level scope, portability, and contribution guidance
- formal reusable skills for:
  - RL system bootstrap
  - task contract design
  - metrics and evaluation layering
  - HPC experiment operations
  - paper reproduction audit
  - research project workflow routing
- bundled templates that make direct reuse easier

## Why This Can Be The First Baseline

- the library structure is now stable enough to reuse
- the main cross-project skill boundaries are explicit
- the upstream source-of-truth boundary versus project docs is clear

## Why This Is Not `v1.0.0`

- the library is reusable now, but still early in real downstream validation
- more project use is expected to refine templates and workflow boundaries
